NoteIce cream

An ice cream truck owner recorded the number of cones sold and the day’s high temperature (in °F) on 60 summer days. They want to predict how many cones they’ll sell, so they know how much to stock.

Dataframe name: icecream

Target variable: sales, the number of cones sold that day.

The first few rows of icecream:

temperature sales
90 385
86 406
66 285
76 334
94 387
94 367

A model has been fit to predict sales from temperature. Here is its output:

# A tibble: 2 × 2
  term        estimate
  <chr>          <dbl>
1 (Intercept)  -121.  
2 temperature     5.65

Reminder: all datasets and libraries are already loaded for you.

Q1 Is this a regression or classification problem?

Show answer

Regression. sales is a continuous value; there are more than 2 possible outcomes.

Q2 Write the mathematical form of the model implied by this output.

Show answer

\[\widehat{\text{sales}} = -121 + 5.65 \cdot \text{temperature}\]

Q3 What would this model predict for a day with a high of 80°F? Round to 2 decimal places, if needed.

Show answer

Using the coefficients in the output:

-121 + 5.65 * 80

which is about 331.

NoteDriving test

A driving school recorded how many hours 60 of its learners practiced driving before their road test, and whether they passed. The school wants to predict which learners will pass, so it can suggest more practice to the others.

Dataframe name: driving

Target variable: result, whether the learner passed ("pass") or failed ("fail") the road test.

The first few rows of driving:

practice_hours result
32 pass
12 fail
29 pass
9 fail
38 pass
37 pass

A model has been fit to predict result from practice_hours. Here is its output:

# A tibble: 2 × 2
  term           estimate
  <chr>             <dbl>
1 (Intercept)      -3.17 
2 practice_hours    0.146

Reminder: all datasets and libraries are already loaded for you.

Q1 Is this a regression or classification problem?

Show answer

Classification. result has two categories, "pass" and "fail".

Q2 Write the mathematical form of the model implied by this output.

Show answer

\[\hat{P}(\text{result} = 1) = \frac{1}{1 + e^{-(-3.17 + 0.146 \cdot \text{practice\_hours})}}\]

Q3 What would this model predict for a learner who practiced for 20 hours? Round to 2 decimal places, if needed.

Show answer

Using the coefficients in the output:

1 / (1 + exp(-(-3.17 + 0.146 * 20)))

which is about 0.44. So the model thinks there is about a 44% chance that this learner will pass.

Q4 If classification, convert the target variable column to 1 or 0 (or equivalently, TRUE and FALSE). If regression, leave this blank.

Hint: use mutate(), and possibly ifelse() (there’s more than one way to do this).

Show answer 
driving <- mutate(driving, result = result == "pass")

Or, with ifelse():

driving <- mutate(driving, result = ifelse(result == "pass", 1, 0))

Q7 Evaluate the model on driving:

  • If this is a regression problem, compute the MSE.
  • If this is a classification problem, add a new column decision that is 1 if the prediction is above 0.5 and 0 otherwise. Then calculate MCR, Precision, and Recall.
Show answer 
driving <- mutate(driving, decision = ifelse(result_hat > 0.5, 1, 0))

# MCR: the fraction of rows where the decision is wrong
summarize(driving, MCR = mean(result != decision))
# A tibble: 1 × 1
    MCR
  <dbl>
1 0.233
# Precision: of the rows where the decision is 1, the fraction that really are 1
driving |>
  filter(decision == 1) |>
  summarize(Precision = mean(result == 1))
# A tibble: 1 × 1
  Precision
      <dbl>
1      0.75
# Recall: of the rows that really are 1, the fraction where the decision is 1
driving |>
  filter(result == 1) |>
  summarize(Recall = mean(decision == 1))
# A tibble: 1 × 1
  Recall
   <dbl>
1  0.844

Or all at once, by counting the four cells of the confusion matrix:

driving |>
  summarize(
    TP = sum(result == 1 & decision == 1),
    FP = sum(result == 0 & decision == 1),
    TN = sum(result == 0 & decision == 0),
    FN = sum(result == 1 & decision == 0)
  ) |>
  mutate(
    MCR = (FP + FN) / (TP + FP + TN + FN),
    Precision = TP / (TP + FP),
    Recall = TP / (TP + FN)
  )
# A tibble: 1 × 7
     TP    FP    TN    FN   MCR Precision Recall
  <int> <int> <int> <int> <dbl>     <dbl>  <dbl>
1    27     9    19     5 0.233      0.75  0.844

NoteGym membership

A gym recorded, for 60 of its members, how many times a month they visit on average, how many months they’ve been a member, and whether they canceled their membership the following month. The gym wants to predict who is about to cancel, so it can offer them a discount.

7 15 no
