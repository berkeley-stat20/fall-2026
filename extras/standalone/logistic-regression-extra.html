Logistic Regression Playground

How to use this tool

  1. Each dot is one penguin: male at 1, female at 0. The black curve is the model's predicted probability that a penguin is male, given its weight.
  2. Hover over a penguin to see how the model calculates its probability of being male.
  3. Scroll down to read the R code that fit the model and the formula it uses to make predictions.
  4. Then click Set decision threshold to turn probabilities into male/female predictions. Drag the threshold up and down and watch how the confusion matrix and error rates change.

How the model predicts

1. Linear component z = −5.16 + 0.00124 × body_mass_g 2. Send it through the sigmoid to get a probability P(male) = 11 + e−z 3. Turn the probability into a prediction
Predict male if P(male) > 0.5
Example: a 4000 g penguin has z = −5.16 + 0.00124 × 4000 = −0.20, so P(male) = 1 / (1 + e0.20) = 0.45. Predict female.
